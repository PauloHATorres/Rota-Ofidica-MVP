# SINTA WebApp

Frontend inicial do SINTA construído com React + Vite, criado mobile-first e preparado para integração posterior com a IA.

## Rodar localmente

```bash
npm install
npm run dev
```

## Estrutura atual

- Shell global responsivo
- Header desktop
- Bottom navigation mobile
- Página Início fiel ao conceito visual
- Upload de imagem e captura via câmera
- Preview da imagem
- Rotas para Centros, Informações e Sobre
- aiService separado para futura integração do modelo
